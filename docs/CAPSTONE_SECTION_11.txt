INFORMACIÓN TÉCNICA COMPLEMENTARIA:

Stack: Next.js 15 + React 19 + TypeScript + Supabase + Tailwind CSS

Ambiente local:
1. npm install
2. npm run dev
3. App en http://localhost:3000

Ambiente producción: https://pulperia.vercel.app

Base de datos: Supabase con 10 tablas normalizadas y migraciones reproducibles desde cero

Antes de que el profesor pruebe:
1. Crear usuario demo en Supabase Auth: demo@pulperia.test / DemoPass123!
2. Ejecutar script SQL (supabase/demo-setup.sql) para poblar datos de prueba
3. Verificar que hay 4 clientes, 10 productos, 3 ventas, 2 créditos en la BD

Health check (verifica que API funciona): GET http://localhost:3000/api/health → {status: "ok"}

Seguridad:
- Autenticación: Supabase Auth con tokens JWT seguros
- Autorización: Cada usuario solo ve sus datos (Row Level Security)
- Validación: Inputs validados en frontend y backend
- Auditoría: Todas las acciones quedan registradas en BD con timestamp y usuario

Duracion total del recorrido: 5 minutos
