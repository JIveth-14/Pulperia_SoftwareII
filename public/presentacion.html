📦 Pulpería Manager

Sistema Integral de Gestión para Tiendas de Barrio

🔴 Problema: Los Desafíos de una Pulpería sin Digitalización

Las pulperías y pequeñas tiendas de barrio enfrentan desafíos operacionales críticos que limitan su crecimiento y rentabilidad. Jéssica, propietaria de una pulpería en el barrio, trabaja sola sin herramientas digitales. Cada día enfrenta los mismos problemas: no puede rastrear quién le debe dinero de forma confiable, pierde ingresos porque no sabe cuántos fiados tiene pendientes, frecuentemente se queda sin stock de productos populares, no tiene registro histórico de sus ventas, y sus apuntes en papel se pierden o se mojan.

Sin un sistema digital, la propietaria trabaja bajo estrés constante, toma decisiones sin datos reales, y su negocio no puede escalar. Cada cliente que pregunta cuánto debe es una sorpresa desagradable, cada reorden de productos es un adivinanza, y cada cierre de mes es imposible sin hojas de cálculo manuales. Esto genera pérdida de dinero, baja productividad y limitaciones severas al crecimiento del negocio.

✅ Solución: Pulpería Manager, Digitalización Simple y Poderosa

Pulpería Manager es una aplicación web moderna diseñada específicamente para pulperías y pequeños comercios de barrio. No requiere computadora, funciona desde cualquier teléfono, y tiene una interfaz tan intuitiva que no necesita capacitación técnica. Jéssica puede acceder desde su celular en cualquier momento y lugar, ver exactamente quién debe, cuánto debe, cuándo pagó, y tener control total de su inventario.

Con Pulpería Manager, la propietaria obtiene automatización de tareas operacionales, control total de deudas en tiempo real, alertas inteligentes de stock, reportes claros de ingresos, y datos sincronizados en la nube. Todo en una plataforma segura, rápida y confiable que crece con el negocio. La interfaz es tan simple que cualquiera puede usarla sin necesidad de capacitación. Los datos están protegidos con encriptación y se sincronizan automáticamente.

Cada funcionalidad fue desarrollada escuchando los desafíos reales que enfrenta Jéssica en su día a día. 🛒 Registro de Ventas

Crea ventas con múltiples productos. El total se calcula automáticamente y el stock se descuenta en tiempo real. Historial completo de transacciones.

📊 Reportes y Estadísticas

Visualiza resumen de fiados pendientes, productos agotados, ingresos totales, y tendencias de ventas por período. Datos de negocio a tu alcance.

📱 Acceso Móvil y Responsivo

Funciona perfectamente en celular, tablet y computadora. Datos sincronizados automáticamente en la nube. Accede desde cualquier dispositivo.

🏗️ Arquitectura del Sistema

Pulpería Manager está construida con una arquitectura moderna basada en principios de software sólidos. El sistema separa claramente las responsabilidades entre el frontend (interfaz del usuario), el backend (lógica de negocio) y la base de datos (almacenamiento persistente). Esta separación garantiza que la aplicación sea escalable, mantenible y confiable.

Componentes Principales

Frontend (Next.js 15): Interfaz responsiva que funciona en cualquier dispositivo. Utiliza React 19 con TypeScript para garantizar código type-safe. Styled con Tailwind CSS para un diseño limpio y profesional que se adapta a móviles, tablets y computadoras.

API (Next.js Server Actions): Maneja toda la lógica de negocio. Valida datos, aplica reglas de negocio, y se comunica con la base de datos de forma segura. Optimizado para rendimiento y seguridad.

Base de Datos (Supabase PostgreSQL): Almacena datos de clientes, productos, ventas y fiados. Incluye triggers automáticos que aplican reglas: pagos reducen saldo, ventas descuentan stock, alertas se generan automáticamente. Garantiza integridad e consistencia de datos.

¿Por qué estas tecnologías?

Next.js 15: Framework moderno que permite desarrollo full-stack. Ofrece Server-Side Rendering, API routes integradas, y es optimizado para Vercel. Ideal para aplicaciones web responsivas y rápidas que funcionan perfectamente en mobile.

TypeScript: Proporciona seguridad de tipos que previene errores en tiempo de compilación. Mejora significativamente la mantenibilidad del código y reduce bugs en producción. Garantiza confiabilidad.

Tailwind CSS: Framework utility-first que permite construir interfaces profesionales sin escribir CSS personalizado. Asegura consistencia visual y es fácil de personalizar según necesidades.

Supabase: Backend PostgreSQL como servicio con autenticación integrada, realtime sync y almacenamiento en la nube. Reduce significativamente la complejidad de infraestructura. Datos seguros y disponibles siempre.

PostgreSQL: Base de datos relacional confiable, con triggers y funciones avanzadas que permiten implementar lógica de negocio compleja directamente en la base de datos. Garantiza integridad referencial y consistencia.

📖 Manual de Uso Paso a Paso

Pulpería Manager fue diseñada para ser intuitiva y fácil de usar. No requiere capacitación técnica. Cualquier persona puede aprender a usarla en minutos. Aquí te mostramos los pasos básicos para empezar a usar el sistema en tu pulpería.

Paso 1: Registrarse y Acceder

Ingresa a Pulpería Manager con tu email y contraseña. Si es tu primer acceso, haz clic en "Crear cuenta" y sigue los pasos simples. Tu información está protegida y encriptada. Una vez registrada, accedes con tus credenciales desde cualquier dispositivo. Solo necesitas internet.

Paso 2: Registrar Clientes

Desde el menú principal, ve a "Clientes" y haz clic en "Agregar cliente". Completa: nombre (obligatorio), teléfono (muy importante para contactar) y dirección (opcional). Guarda y el cliente queda registrado. Puedes agregar todos los clientes de tu pulpería, y cada uno tendrá su perfil con historial completo de compras.

Paso 3: Cargar Productos al Inventario

Accede a "Inventario" y haz clic en "Agregar producto". Ingresa: nombre del producto, precio de venta, cantidad actual en stock, y stock mínimo (sugerido 5 unidades). El sistema alertará automáticamente cuando el stock caiga por debajo del mínimo, recordándote que es hora de reponer.

Paso 4: Registrar una Venta

Ve a "Ventas" y haz clic en "Nueva venta". Selecciona o busca el cliente, agrega productos (cantidad), y el sistema calcula el total automáticamente. Marca la venta como "Pagado al contado" o como "Fiado". Guarda. El stock se descuenta automáticamente. Así de simple.

Paso 5: Gestionar Fiados y Pagos

Si una venta es fiada, se crea automáticamente un registro en "Fiados". Aquí ves: cliente, monto total, saldo pendiente, fecha, y estado. Para registrar un pago, selecciona el fiado, haz clic en "Registrar pago", ingresa el monto pagado. El saldo se actualiza automáticamente. Si es el monto completo, el estado cambia a "Pagado".

Paso 6: Ver Reportes en el Dashboard

El dashboard (pantalla de inicio) muestra un resumen completo: fiados pendientes (cuánto te deben en total), productos con bajo stock (qué reponer urgente), ingresos del mes (dinero que recaudaste), y últimas transacciones. Todo de un vistazo para tomar decisiones rápidas.

Paso 7: Búsquedas Rápidas

En cada sección (Clientes, Fiados, Productos, Ventas) puedes buscar por nombre o filtrar por estado. Esto es muy útil cuando tienes muchos registros y necesitas encontrar información específica rápidamente sin perder tiempo.
