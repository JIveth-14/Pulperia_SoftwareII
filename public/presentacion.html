📦 Pulpería Manager

Sistema integral de gestión para tiendas de barrio

Problema Solución Funcionalidades Arquitectura Tecnologías Manual de Uso Cliente Autor

🔴 El Problema

Las pulperías y pequeñas tiendas de barrio enfrentan desafíos operacionales críticos. La propietaria trabaja sola, atiende clientes, gestiona inventario y administra deudas de forma manual. Sin herramientas digitales, es imposible:

  • Rastrear deudores: Mantener registro de quién debe, cuánto debe y hace cuánto tiempo
  • Controlar inventario: Saber qué productos hay, cuándo reponer, qué está agotado
  • Registrar ventas: No hay historial claro de ingresos ni análisis de movimiento
  • Generar reportes: Imposible visualizar datos de negocio sin sistemas manuales
  • Acceso desde teléfono: La propietaria no usa computadora, necesita usar su celular

Resultado: Pérdida de dinero, estrés operacional y crecimiento limitado del negocio.

✅ La Solución

Pulpería Manager es una aplicación web moderna, responsiva y accesible desde cualquier teléfono. Diseñada específicamente para pulperías y pequeños comercios, permite digitalizar todas las operaciones con una interfaz intuitiva que no requiere capacitación técnica.

Con Pulpería Manager, la propietaria puede:

  • ✓ Registrar clientes y mantener su historial de compras
  • ✓ Gestionar fiados (deudas) con estado en tiempo real
  • ✓ Registrar pagos parciales y seguimiento automático
  • ✓ Controlar inventario con alertas de bajo stock
  • ✓ Registrar ventas y obtener reportes de ingresos
  • ✓ Acceder desde cualquier celular, en cualquier momento
  • ✓ Datos sincronizados y seguros en la nube

⭐ Funcionalidades Principales

👥 Gestión de Clientes

Registra clientes con nombre, teléfono y dirección. Visualiza el historial de compras y saldo pendiente de cada uno.

💳 Control de Fiados

Registra deudas, realiza pagos parciales, marca como pagado. Estado automático: pendiente, parcial o pagado.

📦 Inventario Inteligente

Carga productos con precio y stock. Alertas automáticas cuando el stock cae por debajo del mínimo.

🛒 Registro de Ventas

Crea ventas con múltiples productos. Total se calcula automáticamente y el stock se descuenta en tiempo real.

📊 Reportes y Estadísticas

Visualiza resumen de fiados pendientes, productos agotados, ingresos totales y tendencias de ventas.

📱 Responsive & Offline-Ready

Funciona en celular, tablet y computadora. Datos sincronizados con la nube automáticamente.

🏗️ Arquitectura del Sistema

Modelo de Datos Relacional

La base de datos está normalizada y diseñada para manejar operaciones complejas con integridad referencial. Cada tabla representa una entidad del negocio, con relaciones claras que garantizan consistencia de datos.

CLIENTES (id, nombre, teléfono, dirección) ↓ FIADOS (id, cliente_id, monto_total, saldo_pendiente, estado) ↓ PAGOS (id, fiado_id, monto_pagado, fecha_pago) PRODUCTOS (id, nombre, precio, stock, stock_mínimo) ↓ VENTAS (id, total, fecha) ↓ DETALLE_VENTA (id, venta_id, producto_id, cantidad, precio_unitario) Triggers automáticos: • Al crear pago → reduce saldo_pendiente • Al crear detalle_venta → descuenta stock • Al actualizar stock → verifica alertas

Flujo de Datos

  1. Frontend (Next.js): Interfaz responsiva que captura datos del usuario
  2. API (Next.js Server Actions): Valida datos y ejecuta lógica de negocio
  3. Base de Datos (Supabase/PostgreSQL): Almacena datos, aplica reglas, genera triggers
  4. Sincronización en tiempo real: Cambios se replican automáticamente a todos los clientes

📖 Manual de Uso Paso a Paso

Paso 1: Registrarse y Acceder

Crear tu cuenta

Ingresa a Pulpería Manager con tu email y contraseña. Si es tu primer acceso, haz clic en "Crear cuenta" y sigue los pasos. Tu información está protegida y encriptada.

Paso 2: Registrar Clientes

Agregar un nuevo cliente

Desde el menú principal, ve a "Clientes" y haz clic en "Agregar cliente". Completa: nombre, teléfono (obligatorio) y dirección (opcional). Guarda y listo. El cliente queda registrado en el sistema.

Paso 3: Agregar Productos al Inventario

Cargar productos

Accede a "Inventario" y haz clic en "Agregar producto". Ingresa: nombre, precio, cantidad en stock y stock mínimo (sugerido: 5). El sistema te alertará automáticamente cuando el stock baje del mínimo.

Paso 4: Registrar una Venta

Crear venta

  1. Ve a "Ventas" → "Nueva venta"
  2. Selecciona o crea un cliente
  3. Agrega productos: busca el producto, ingresa cantidad
  4. El total se calcula automáticamente
  5. Marca como "Pagado al contado" o como "Fiado"
  6. Guarda. El stock se descuenta automáticamente.

Paso 5: Gestionar Fiados

Registrar una deuda (fiado)

Si una venta es fiada, se crea automáticamente un registro en "Fiados". Puedes ver: cliente, monto total, saldo pendiente, estado (pendiente/parcial/pagado).

Registrar un pago parcial

En "Fiados", selecciona el fiado y haz clic en "Registrar pago". Ingresa el monto pagado. El saldo se actualiza automáticamente. Si es el monto completo, el estado cambia a "Pagado".

Paso 6: Ver Reportes

Dashboard (inicio)

El dashboard muestra un resumen de: fiados pendientes (cuánto te deben), productos con bajo stock, ingresos del mes, últimas transacciones.

Paso 7: Búsquedas y Filtros

Encontrar información rápido

En cada sección (Clientes, Fiados, Productos) puedes buscar por nombre o filtrar por estado. Esto es útil cuando tienes muchos registros.
