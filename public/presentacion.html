🏪 Pulpería

Sistema Integral de Gestión para Tu Negocio

1. El Problema

Los pequeños negocios como pulperías, tiendas de barrio y comercios minoristas en Centroamérica enfrentan desafíos críticos en su operación diaria:

  • Falta de control de inventario: No saben cuántos productos tienen en stock, qué se vende más y cuándo reponer.
  • Gestión de créditos manual: Registran deudas de clientes en cuadernos que se pierden o dañan, causando pérdidas económicas.
  • Sin reportes de ventas: Desconocen cuáles son sus mejores productos, márgenes de ganancia reales y tendencias de ventas.
  • Falta de digitalización: Operan con cash y papelería, sin trazabilidad ni respaldo de transacciones.
  • Acceso limitado offline: Si la conexión cae, el negocio se detiene porque toda la información está en la nube.

2. La Solución

Pulpería es una plataforma web moderna y accesible que centraliza todas las operaciones de tu negocio en un único lugar:

📱 Acceso desde cualquier dispositivo

Web app responsive que funciona en desktop, tablet y celular. Accede desde cualquier lugar.

⚡ Funciona sin internet

Service Worker con cache-first strategy: registra ventas offline y sincroniza cuando regresa la conexión.

🔐 Seguridad enterprise

Content Security Policy, HTTPS obligatorio, autenticación con Supabase, encriptación de datos.

📊 Reportes en tiempo real

Dashboards, análisis de ventas, control de deudas de clientes y alertas de stock bajo.

3. Funcionalidades Principales

📦 Gestión de Inventario

  • Registro de productos con precio, stock, código de barras
  • Alertas automáticas cuando stock baja del mínimo
  • Búsqueda rápida y filtrado por categoría
  • Historial de movimientos de stock

👥 Gestión de Clientes y Créditos

  • Registro de clientes con contacto y dirección
  • Control de deudas ("fiados") con fecha de vencimiento
  • Estado de pagos (pendiente, pagado, parcial)
  • Recordatorios automáticos de pagos vencidos

💰 Registro de Ventas

  • Interfaz rápida para registrar ventas en punto de venta
  • Soporte para ventas al contado y a crédito
  • Cálculo automático de totales y cambio
  • Recibos digitales imprimibles

📊 Reportes y Análisis

  • Dashboard con métricas clave: ventas del día, productos top, deudas pendientes
  • Reportes por período (diario, semanal, mensual)
  • Gráficos de tendencias de ventas
  • Análisis de márgenes de ganancia por producto

4. Arquitectura Técnica

Pulpería fue construida con una arquitectura moderna y escalable, pensada para ser mantenible y performante:

🏗️ Stack Tecnológico

  • Frontend: Next.js 14 con TypeScript para renderizado SSR/SSG y máximo rendimiento
  • Base de Datos: PostgreSQL en Supabase con autenticación integrada
  • Offline-first: Service Worker con estrategia cache-first para funcionalidad sin internet
  • Estilos: Tailwind CSS para UI responsive y consistente
  • Seguridad: Content Security Policy, HTTPS, validación en cliente y servidor

📡 Flujo de Datos

Cliente (Next.js) → API Routes (Next.js) → Base de datos (Supabase PostgreSQL)

Cuando no hay conexión, el Service Worker intercepta peticiones y las guarda localmente, sincronizando cuando regresa la conexión mediante Background Sync API.

✅ Garantías de Calidad

  • Testing: 26+ casos de prueba con Jest/Testing Library
  • CI/CD: GitHub Actions valida tipado TypeScript, linting, builds y tests en cada push
  • Code Quality: SonarCloud analiza bugs, vulnerabilidades y code smells
  • Cobertura: Reportes de cobertura de tests con LCOV en cada run

6. Manual de Uso - Paso a Paso

🚀 Primeros pasos

Paso 1: Registro y Login

Accede a https://pulperia.vercel.app, crea tu cuenta con email y contraseña. Tu datos se guardan en Supabase de forma segura.

Paso 2: Configurar Productos

Ve a "Inventario" → "Agregar Producto". Llena nombre, precio de compra, precio de venta, stock inicial y stock mínimo. El sistema te alerta cuando baje del mínimo.

Paso 3: Registrar Clientes

Accede a "Clientes" → "Nuevo Cliente". Ingresa nombre, teléfono y dirección. Estos datos te permitirán registrar créditos ("fiados").

Paso 4: Hacer una Venta

En "Ventas" (Punto de Venta), busca productos, agrega cantidades, elige si es venta al contado o a crédito. Si es a crédito, selecciona el cliente. El sistema descuenta automáticamente del inventario.

Paso 5: Ver Reportes

En "Dashboard", verás resumen del día: total de ventas, transacciones, deudas pendientes. En "Reportes", filtra por período y descarga datos en CSV.

Paso 6: Gestionar Deudas

En "Clientes", visualiza la deuda de cada uno. Marca como "Pagado" cuando recibas dinero. El sistema registra el historial de pagos.

📱 Modo Offline

Si se cae internet, la app sigue funcionando. Todas tus acciones se guardan localmente. Cuando regresa la conexión, se sincroniza automáticamente con los servidores sin perder datos.

7. Para Quién Es Pulpería

Pulpería fue diseñada específicamente para:

  • Pequeños comerciantes: Dueños de pulperías, tiendas de barrio, abarroterías en Centroamérica
  • Negocios sin sistema actual: Los que operan con cuadernos, calculadora y efectivo
  • Conectividad limitada: Zonas donde el internet es intermitente (funciona offline)
  • Presupuesto limitado: Es más económico que ERP empresariales y no necesita técnico
  • Usuarios de celular: Interfaz responsive que funciona en cualquier dispositivo

💡 Beneficios Concretos

  • Incremento de ventas: Sabes qué vende más y repones a tiempo
  • Reducción de pérdidas: Recuperas deudas de clientes que antes se perdían
  • Ahorro de tiempo: Automatizas cálculos y registros manuales
  • Decisiones basadas en datos: Reportes te muestran tendencias reales
  • Tranquilidad: Backups automáticos en Supabase, no pierdes datos
